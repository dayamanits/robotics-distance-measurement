# Robotics Distance Measurement Simulation

A beginner Python project simulating an ultrasonic sensor for obstacle detection in robotics.

## How it works
- Input the distance to an obstacle in centimeters.
- If distance is 10 cm or less: STOP warning.
- If distance is 30 cm or less: WARNING.
- Otherwise: safe to move.

## Technology
- Python 3
- Robotics logic
- Obstacle avoidance simulation
